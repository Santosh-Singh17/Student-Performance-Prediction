# 🎓 Student Performance Prediction System

## 📌 Project Overview

The **Student Performance Prediction System** is a Machine Learning web application developed using **Python** and **Streamlit**. The system predicts a student's **Exam Score** using **Linear Regression** and determines whether the student will **Pass or Fail** using **Logistic Regression** based on study-related inputs.

---

## 🚀 Features

* Predicts Student Exam Score
* Predicts Pass/Fail Status
* User-friendly Streamlit Web Interface
* Data Preprocessing and Feature Scaling
* Exploratory Data Analysis (EDA)
* Machine Learning Model Training
* Fast and Accurate Predictions

### Logistic Regression

---

## 📈 Project Workflow

1. Load the dataset
2. Clean and preprocess the data
3. Perform Exploratory Data Analysis (EDA)
4. Apply Feature Scaling
5. Split the dataset into training and testing sets
6. Train Linear Regression and Logistic Regression models
7. Evaluate model performance
8. Save trained models
9. Deploy the application using Streamlit

---

## ▶️ How to Run the Project

1. Clone the repository.

2. Install the required libraries.

```
pip install -r requirements.txt
```

3. Run the Streamlit application.

```
streamlit run app.py
```
